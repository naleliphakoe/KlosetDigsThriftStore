Online thrift store, designed to make thrifting easier.  The website is designed using HTML, CSS, JavaScript, PHP and SQL.
The user signs in /logs in, the proceeds to page. When the user has reached the home page they will see items uploaded by other users.
All users can purchase and sell their items. There is a sell option for the users who want to sell their items.
There will be a form that requires personal details to sell your products.
Buying products is easier, add to cart and checkout.
